How to Update Gallery & Website Content

  1. Gallery photos: Open the Gallery tab, click Add Photo Card, enter a title, category (Campus / Corporate / Technical), tag, image URL, and date. The photo appears on the public Gallery page in this browser.
  2. Replace a photo: Host the file or put it in assets/images/, then paste that URL. To change an existing card, delete it and add it again.
  3. Events ticker: Use the Events tab. New items show on the homepage ticker and Events page.
  4. 3 Pillars & modules: Open the 3 Pillars & Modules tab. Edit titles, subheadings, bullets, and duration on the three vertical cards. Add extra course/module cards for AI, Automation, or Operational Excellence pages.
  5. Banners: Replace the image file using the same name (for example slide_industrial_freshers.jpg) and refresh.
  6. Leads: Demo and contact inquiries appear under Leads. Export CSV from the dashboard when needed.

This admin portal stores content in the browser. After going live, upload the same images to the hosting assets/images folder so visitors can see them.
